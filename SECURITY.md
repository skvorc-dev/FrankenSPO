# Security policy

FrankenSPO has not yet published a production-ready release. Please use GitHub's private vulnerability reporting when available; do not expose suspected security vulnerabilities, credentials, or sensitive data in public issues. Supported version and contact details will be added ahead of any production release.

Security requirements include parameterized SQL values, validated identifiers, explicit raw SQL trust boundaries, mandatory enforcement of declared tenant/row/field restrictions, and fail-closed unsupported mappings. Requirements are not claims that the implementation exists.
