| D-25 | 2026-10-27 | **In sync with .NET LTS** (owner): build on the latest .NET 10 LTS SDK patch (`global.json`: 10.0, latest feature band, no previews); runtime packages (`Microsoft.Data.Sqlite`, `Microsoft.Extensions.*`, `System.*`) on the latest **10.0.x** patch, never the next non-LTS major. The source generator references the Roslyn version of the first LTS band (**5.0.0** for .NET 10, C# 14), because a generator built against a newer compiler is silently skipped on older SDK bands (CS9057, verified on SDK 10.0.113). Security fixes for the compiler reach users through their SDK patch; the reference is compile-time only. CI builds on the 10.0.1xx band to prove this. Revisit when .NET 12 LTS ships. Replaces nothing; implements F-08. |
| D-26 | 2026-10-27 | **LTS release rule** (owner). Until v1 is production: LTS only (D-25). After v1: development may move to a non-LTS (STS) .NET on a separate line, but anything built on a non-LTS .NET is released **only as a preview** (`vX.Y.Z-preview.N`, NuGet prerelease). **Only builds on an LTS .NET are production, signed-off releases**; non-LTS work becomes production when it ships on the next LTS. Amends D-23 and D-25. |
| D-27 | 2026-10-27 | **App IDs** (owner): Sferix is a brand of Skvorc Dev. Product domains are for websites only. FrankenSPO needs an app ID only from its first installable sample. |
| D-28 | 2026-10-27 | **Secret scanning and push protection** (owner, all projects): always on for every public repo (FrankenSPO, MiddleTier, WebApi done), enabled without asking. A private repo records the rule and turns both on the moment it becomes public. |
| D-29 | 2026-10-27 | **ObjectSpace (P1):** single-threaded per instance (misuse is detected and reported). API is async-first with `CancellationToken`, plus sync twins. Each SaveChanges runs in its own transaction; no external connection/transaction sharing and no public `Flush()` in P1. An unknown commit outcome raises `SpoCommitUncertainException` with a summary of the unit's changes, and that ObjectSpace can no longer be used. |
| D-30 | 2026-10-27 | **Tracking (P1):** after a failed, rolled-back save the user's values stay and stay dirty; the committed baseline does not move. Dirty checks use a per-type comparer chosen by the generator (decimal exact, DateTime by ticks and kind, `byte[]` by content, strings ordinal). The flushed baseline exists only inside SaveChanges. |
| D-31 | 2026-10-27 | **Optimistic concurrency is in the PoC:** an integer version column, incremented on every update; a mismatch raises its own exception and writes nothing. |
| D-32 | 2026-10-27 | **Queries (P1):** LINQ subset = Where (comparisons, `&&`, `\|\|`, `!`, null checks), string StartsWith/EndsWith/Contains (escaped LIKE), OrderBy/ThenBy (+Descending), Skip/Take, Select to DTO, First/FirstOrDefault/Single/SingleOrDefault, Count, Any, **plus GroupBy and Sum/Min/Max/Average**. Anything else raises `SpoQueryNotSupportedException`, which names the operator but never contains SQL text or values. String comparison is ordinal and case-sensitive. SQL identifiers are limited to 63 characters on every provider. |
| D-33 | 2026-10-27 | **Policies:** P1 has no policy engine; a model that declares a tenant/row/field policy fails at activation (fail closed). Later, policies are attributes read by the generator, and the host supplies tenant/actor through a small context interface. Raw SQL is rejected on entities with a policy. Activation = building the compiled model at startup; all capability and policy checks run then. |
| D-34 | 2026-10-27 | **Providers and schema:** provider interfaces live in `Sferix.SPO.Abstractions`. Core turns metadata into a provider-neutral schema model and validates it; a provider only renders DDL in its dialect. SQLite: WAL journal, `foreign_keys` on, a busy timeout, one connection per ObjectSpace. |
| D-35 | 2026-10-27 | **Entities (P1):** `SPOBaseObject` is a simple base class with shared columns (UUIDv7 Id, CreatedAt/ModifiedAt, IsDeleted/DeletedAt, version); no inheritance mapping or polymorphic queries. Identity map key = entity type + key. Audit records UTC timestamps from an injectable `TimeProvider`; no actor in P1. SoftDelete = tracking state `Deleted` plus the columns; deleted rows are hidden from queries unless `IncludeDeleted()` is used. |
| D-36 | 2026-10-27 | **Modules and packages:** modules are activated by explicit registration at startup (no assembly scanning). API maturity = feature status in `features.json` plus .NET's `[Experimental]` on preview APIs; PublicApiAnalyzers are added at P2. NuGet: one package per assembly (generator shipped inside the Core package) plus a convenience package `Sferix.SPO` = Core + SQLite. Module naming: assembly, package and root namespace `Sferix.SPO.<Module>` (e.g. `Sferix.SPO.Security`), entry class `<Module>Module` (`SecurityModule`, registered with `AddModule<SecurityModule>()`). Only modules can be registered: `AddModule<T>()` requires `T : ISpoModule` (compile error otherwise), and an analyzer reports an error for a module class whose name does not end in `Module`; shared contracts Core needs live in `Sferix.SPO.Abstractions`. |
| D-37 | 2026-10-27 | **Declaring entities:** `[SpoEntity("<guid>")]` on a `partial` class; the GUID is the stable entity ID and never changes on rename. Each persistent property has `[SpoField(n)]`, a positive number unique within the entity and never reused, like protobuf field numbers. The source generator reads only these and reports missing/invalid/duplicate IDs and non-partial classes as errors. A code fix that inserts a new GUID comes later. |
| D-38 | 2026-10-27 | **Worker chains and context** (owner): one chain per worker session, new cards added to it by message. The main agent reads each worker's context with the app's usage tool; **Haiku rotates at ~60 %, Sonnet/Opus at ~70 %**: the worker finishes its current card, opens its PR, names the next card and stops with `ROTATE`. The new session gets the same brief plus "cards X–Y are merged, start with Z" (BOARD.md and the PRs are the state; no summary). Sizes per model: Haiku S and small M code; Sonnet M code; Opus design. Every brief names the model, the stop conditions (context %, end of queue) and the files of parallel workers it must not touch. The main agent also checks the account's weekly limit before starting chains. |
| D-39 | 2026-10-27 | **Capabilities:** the runtime capability set is code: a `SpoCapability` enum in `Sferix.SPO.Abstractions`, declared by each provider and checked against the model's required capabilities at activation (`SpoCapabilityMissingException`). `features.json` stays the repository's statement of feature status for people; it is not read at runtime and the two are not the same list. A capability name is added only with the card that first checks it. Answers `providers.md` open questions 2 and 3. |
